## ⚡ Start Immediately

### Local Development
```bash
npm install
npm run dev
# Open http://localhost:3000
```

### Deploy to Vercel
```bash
git push origin main
# Then: vercel.com → Import repo → Deploy
```

## 📊 What's Inside

8 real-time financial indicators:
- **Mag7 Weight** — Tech concentration
- **Shiller P/E** — Valuation extremes
- **VIX** — Market volatility
- **Breadth** — Market participation
- **10Y-2Y Spread** — Recession signals
- **ERP** — Risk compensation
- **HY Spreads** — Credit stress
- **Unemployment** — Real economy

**Composite Risk Score:** 0-100 scale showing systemic risk level
